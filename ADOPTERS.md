For the full definition of an adopter, see the [CNCF TOC FAQ](https://github.com/cncf/toc/blob/main/FAQ.md#what-is-the-definition-of-an-adopter).

## Adopter types

Adopters may fall into one or more of the following categories:

| Type | Description |
| ---- | ----------- |
| CNCF End-User Member | Organizations that are [CNCF End-User members](https://www.cncf.io/people/end-user-community/) and use the project internally |
| End-User Organization | Organizations (not CNCF End-User members) that use the project internally or build upon it but do not sell it externally as a service |
| Service Provider | Organizations that repackage the project as a core component of a service offering (cloud providers, SaaS, managed services) |
| Project | Open source projects that integrate with or depend on this project |
| Consultancy | Organizations that assist others in developing solutions using this project |

Service Provider customers are considered transitive adopters and should not be listed individually.
